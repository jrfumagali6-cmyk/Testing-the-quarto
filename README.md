# Testing-the-quarto


During my first year of my Ph.D., I had time-series classes with my future advisor. All the classes were in R, and I attended a statistics conference where a colleague showed me a new R interface (called Quarto). So I decided to convert the old R scripts to Quarto. Quarto offers a more user-friendly, interactive interface. 

I must confess that  I used Claude a lot to help me to convert the R scripts to the Quarto interface. The result is ok in my point of view. 

I am learning how to use Quarto, and I am discovering the interface's new utilities. I am very excited about this.
