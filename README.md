# Testing-the-quarto


During my first year of my Ph.D., I had time-series classes with my future advisor. All the classes were in R, and I attended a statistics conference where a colleague showed me a new R interface (called Quarto). So, I decided to convert the old R scripts to a new version using Quarto. Quarto offers a new interface that's more user-friendly and interactive. 

I must confess that  I used Claude a lot to help me to convert the R scripts to the Quarto interface. The result is ok in my point of view.
